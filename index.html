01—whoami

Full stack, mostly at the layer where agents meet editors.

I'm a full-stack developer in Sydney. Most of my work sits where developer tooling meets language models: skill graphs that show what composes with what, session diffs that record what an agent actually changed, and token-pruning proxies that keep context lean enough to think in.

Before that it was the usual long tail — VR experiments in A-Frame, RSS readers, serverless video pipelines, Salesforce and CodeIgniter integrations. The common thread is small, sharp utilities that do one thing properly and stay out of the way.

I pick the tool per problem: TypeScript for product surfaces, Rust and Go where throughput matters, Python where the ecosystem already solved it. No framework religion, no build step for the sake of one.
